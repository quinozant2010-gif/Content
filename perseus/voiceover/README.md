# Voiceover Sheet — Perseus Was Sent to Kill Medusa… But Who Sent Him?

103 beats, matched one-to-one to `perseus/08-image-prompts.md`. 449 spoken words (excluding labels and cues).

## Files
- `master-voiceover-sheet.csv`: every beat with character, line, delivery note and clip filename
- `polydectes.txt`: POLYDECTES lines only
- `perseus.txt`: PERSEUS lines only
- `danae.txt`: DANAË lines only
- `danae-young.txt`: DANAË (YOUNG) lines only
- `athena.txt`: ATHENA lines only
- `hermes.txt`: HERMES lines only
- `graeae.txt`: GRAEAE lines only
- `medusa.txt`: MEDUSA lines only
- `stheno.txt`: STHENO lines only
- `euryale.txt`: EURYALE lines only
- `stheno-euryale.txt`: STHENO + EURYALE lines only

## Rules
- Only dialogue goes to the voice tool. Speaker labels and bracketed cues are never read aloud.
- `SFX` beats are music/sound effects added in the edit, with no voice.
- `non-verbal` beats (laughs, screams, cackles) are voiced by that character if your tool supports it; otherwise use SFX.
- Save each clip as `beat-NN_character.mp3` and drop it under the video clip with the same beat number.
- Deliver lines at normal pace; the slow feel comes from music and silence between lines.
